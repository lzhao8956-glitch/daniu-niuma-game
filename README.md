## 📖 游戏特色

- **6大主线剧情事件**：入职、述职、AI浪潮、职场日常……
- **11个命运结局**（v2新增3个）：🌊 润学大师（移民/出海赛道）、🏖️ 提前退休（财务自由）、🐂 终极牛马（永世牛马）
- **4项核心属性**：💰存款、📊能力、😊心态、🤝人脉
- **完整数值系统**：你的选择会改变属性，属性决定结局
- **精美暗黑风UI**：移动端适配，深夜摸鱼也能玩

## 🆕 v2 新功能

### 🔄 跳槽模式
可以主动跳槽！不同公司有不同 buff/debuff，每次跳槽影响你的属性走向。跳早了基础不够，跳晚了被裁——选准时机才能逆天改命。

### 🐟 摸鱼指数
新增隐藏「摸鱼指数」属性。摸鱼过高会触发「被裁员」事件，但合理摸鱼搭配技能提升，也能摸出高薪工作。真正的牛马，敢于在老板眼皮底下优雅摸鱼。

### 🏆 排行榜（LocalStorage 本地排行）
每次通关后自动保存成绩，按结局评分排名。排行榜数据存在浏览器本地，多周目也能看到自己的进步曲线。

### 🆕 3个 v2 新结局
| 结局 | 条件 | 说明 |
|------|------|------|
| 🌊 润学大师 | 存款≥8000 + 能力≥700 | 移民北欧/远程出海，彻底逃离内卷 |
| 🏖️ 提前退休 | 存款≥10000 + 心态≥500 | 30岁Fire躺平，靠被动收入环游世界 |
| 🐂 终极牛马 | 心态≤100 + 存款≤500 | 永世不得翻身的社畜——最惨结局 |
