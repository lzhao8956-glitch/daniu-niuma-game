## 📖 游戏特色

- **6大主线剧情事件**：入职、述职、AI浪潮、职场日常……
- **8个命运结局**：技术大佬、财富自由、被AI替代、心态大师……
- **4项核心属性**：💰存款、📊能力、😊心态、🤝人脉
- **完整数值系统**：你的选择会改变属性，属性决定结局
- **精美暗黑风UI**：移动端适配，深夜摸鱼也能玩
